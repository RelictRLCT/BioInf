# Лаба 1
## Команда "Саммит Большой Единицы"
### Состав команды:
1) Нащёкин Никита, ИУ9-72Б

## Запуск:
```shell
python3 main.py
```
*дополнительных библиотек не требуется*

### Инструкция:
В папке `data` лежит два `.fasta` файла (самый большой файл гитхаб залить не дал, 
поэтому его нужно положить туда вручную). При запуске нужно указать название файла 
либо прописать его в коде, изменив `main.py` 
(только название, файл будет взят из папки `data`).

На вход необходимо подать код белка, для которого надо найти похожие.

На выход будут выведены 100 (или меньше) белков, максимально похожих на заданный, 
в порядке убывания похожести.

### Описание:
Честно говоря, я хотел сделать максимально странный и нестандартный метод поиска, 
но получилось на удивление неплохо.

Программа работает следующим образом: на первом шаге вычисляется длина кода заданного 
белка, после чего отсеиваются все белки, длина кода которых меньше `70%` и 
больше `130%` длины кода заданного белка.

После этого для каждого кода оставшегося белка строится матрица биграмм (в виде вектора).

```
Матрица биграмм - матрица, где по столбцам и по строкам 
идут буквы A-Z, а на пересечении двух букв стоит число, 
равное количеству пар из этих двух букв, встречающихся 
в тексте (важен порядок, для удобства первая буква пары 
из строки, вторая - из столбца).

Например, для текста ABC матрица биграмм будет выглядеть 
так:

  A B С
A 0 1 0
B 0 0 1
С 0 0 0
```

Затем вычисляется косинусное сходство `(x, y) / (||x|| * ||y||)` между вектором биграмм входного кода белка и 
векторами биграмм, оставшихся после отсеивания по длине кодов белков из файла.
Затем 100 лучших результатов выводятся на экран.

Такой подход должен давать хорошую устойчивость на смене порядка доменов, 
однако для него не очень хороши атомарные мутации вроде добавления буквы
(так как тогда две старые пары будут уничтожены, а на их месте появятся 
две новые пары букв).

Время работы на большом датасете - в среднем примерно 20 секунд 
(зависит от длины входа).
